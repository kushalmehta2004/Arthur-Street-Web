# Arthur Street Kitchen + Bar | Premium Dining Website

A modern, high-performance landing page for **Arthur Street Kitchen + Bar**, an elegant dining establishment in historic downtown Elmira. This project focuses on a premium user experience with fluid animations, parallax effects, and a responsive design tailored for gourmet hospitality.

## 🍽️ Features

- **Immersive Hero Section**: Features a dynamic video background with parallax layers and smooth scroll-to-content functionality.
- **Interactive Menu Highlights**: Showcases bestsellers and chef recommendations with "Wine Pairing" badges and seasonal indicators.
- **Reservation System**: A clean, user-friendly booking form for table reservations.
- **Chef Spotlight**: Dedicated section highlighting the culinary expertise and credentials of the Executive Chef.
- **Social Integration**: Embedded Instagram feed links and interactive Google Maps integration for easy location finding.
- **Testimonials Slider**: Dynamic guest reviews with a custom-built navigation system.
- **Fully Responsive**: Optimized for seamless viewing across desktops, tablets, and mobile devices.

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid)
- **Styling**: Custom CSS with Parallax effects, Glassmorphism, and CSS Keyframe animations.
- **Interactivity**: Vanilla JavaScript for scroll-spy navigation, sliders, and form handling.
- **Typography**: Premium Google Fonts integration (*Cormorant Garamond*, *Montserrat*, *Dancing Script*).
- **Icons**: Font Awesome 6.0 Pro icons.
